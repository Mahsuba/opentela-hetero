\# OpenTela-Hetero — Week 1 Glossary



\## Programming



\*\*Go\*\* — The programming language we are learning.



\*\*Program\*\* — Instructions written for a computer to execute.



\*\*Variable\*\* — A named place that stores a value.



\*\*String\*\* — Text, such as `"OpenTela"`.



\*\*Integer\*\* — A whole number, such as `25`.



\*\*Struct\*\* — A custom type that groups related information together.



\*\*Node\*\* — In our project, a computer/machine in the compute system.



\*\*CPU\*\* — The processor of a computer.



\## Git



\*\*Git\*\* — A tool that records changes to a project.



\*\*Repository\*\* — A project folder tracked by Git.



\*\*Commit\*\* — A saved checkpoint in Git history.



\*\*Staging area\*\* — The place where changes wait before being committed.



\*\*git status\*\* — Shows the current state of the Git repository.



\*\*git add\*\* — Puts selected changes into the staging area.



\*\*git commit\*\* — Saves staged changes as a checkpoint.



\*\*git log\*\* — Shows the project's commit history.



\*\*Working tree\*\* — The files in your project folder that Git is tracking.



\## Terminal



\*\*cd\*\* — Moves into a folder.



\*\*cd ..\*\* — Moves to the parent folder.



\*\*pwd\*\* — Shows the current folder.



\*\*dir\*\* — Lists files and folders.



\*\*type\*\* — Displays the contents of a text file.



\*\*go run\*\* — Compiles and runs a Go program.



\*\*go build\*\* — Builds a Go program into an executable.
